# SEO8U

Premium space-themed online marketing dashboard.

## Run

```powershell
$env:ADS4U_API_KEY="your-api-key"
node server.js
```

Open `http://localhost:4173`.

The supplied Ads4U username/password is intentionally not stored. Generate an API key in the provider dashboard and configure it through `ADS4U_API_KEY` for production.
